# Rules and data

`nothing-happened-in-m31-resources` is the source of truth when it conflicts with this catalogue.

If the corresponding rule cannot be found in `nothing-happened-in-m31-resources`, this repository is the only source.

Inside the resources repository the order is FAQ, then Journal and Addition, then Liber, then the Age of Darkness rulebook, then Legacy. The full order is in `nothing-happened-in-m31-resources/AGENTS.md`.
